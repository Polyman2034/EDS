# 📊 EDS-Lab-Practical

> **Essentials of Data Science (EDS) — Lab Practicals**

This repository contains my **EDS (Essentials of Data Science) lab practicals**, implemented using Python.

The practicals cover fundamental concepts of **Python programming, data processing, NumPy, Pandas, data cleaning, statistical operations, and data visualization using Matplotlib**.

---

## 📚 Practicals Covered

### 🔹 Practical 1 — Python Fundamentals

Covers basic Python programming concepts such as:

- Conditional statements
- Loops
- Functions
- Recursion
- Fibonacci series
- Pattern printing
- Student marks and grade calculation

---

### 🔹 Practical 2 — Searching & Basic Python Operations

Covers fundamental problem-solving techniques including:

- Linear Search
- Array/list processing
- Finding maximum values
- Basic problem-solving using Python

---

### 🔹 Practical 3 — NumPy

Introduces NumPy and numerical data processing.

Topics include:

- NumPy arrays
- Array dimensions, shape and size
- Matrix operations
- Addition and subtraction
- Element-wise multiplication
- Matrix multiplication
- Matrix transpose
- Horizontal and vertical stacking
- Custom sequence generation using `np.arange()`
- Arithmetic operations
- Statistical operations
- Bitwise operations

---

### 🔹 Practical 4 — Pandas & Data Analysis

Focuses on working with structured data using Pandas.

Topics include:

- Reading CSV files
- Grouping data
- Aggregation
- Sales analysis
- Finding the city with the highest product sales
- Finding frequently sold product pairs
- Titanic dataset analysis
- Data cleaning
- Handling missing values
- Feature creation and transformation

---

### 🔹 Practical 5 — Data Visualization

Focuses on analyzing and visualizing the Titanic dataset using:

- Pandas
- Matplotlib
- Bar plots
- Pie charts
- Histograms
- Scatter plots
- Stacked bar charts
- Survival analysis
- Gender-based analysis
- Age distribution
- Fare vs Age analysis
